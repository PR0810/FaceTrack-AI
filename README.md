# 🚀 FaceTrack AI - Smart Attendance System

**FaceTrack** is an innovative AI-powered solution designed specifically for college campuses (like those in Ayodhya Nagar, Bhopal) to solve the age-old problem of manual attendance and "proxy" entries.

## 📌 The Problem (Root Cause)
Traditional attendance taking wastes **15-20 minutes** of every lecture. It is prone to human error and allows students to mark attendance for their absent friends (Proxies).

## ✨ Our Solution
A touch-less, high-speed face recognition portal that automates the entire process.
- **Dual Portal:** Separate, secure dashboards for Students and Teachers.
- **Real-Time Detection:** Instant face matching with the campus database.
- **Transparency:** Students can track their attendance percentage live.
- **Analytics:** Teachers can download detailed Excel reports with one click.

## 🛠 Tech Stack
- **Frontend:** React.js & Tailwind CSS (Modern & Responsive UI)
- **Backend:** Python / Flask (AI Logic)
- **Database:** MySQL / Supabase (Encrypted Student Records)
- **AI Library:** OpenCV & Face-Recognition (Deep Learning)

## 📸 Key Features
- **Smart Registration:** Dynamic forms that change based on user role (Student/Teacher).
- **Face Dataset:** Secure photo upload for initial AI training.
- **Visual Analytics:** Interactive circular progress charts for attendance tracking.
